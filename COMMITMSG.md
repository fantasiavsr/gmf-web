| Commit type | Kegunaan                                     |
| ----------- | -------------------------------------------- |
| `feat`      | Menambahkan fitur baru                       |
| `fix`       | Memperbaiki bug/error                        |
| `refactor`  | Mengubah struktur kode tanpa mengubah fungsi |
| `style`     | Mengubah tampilan atau formatting            |
| `docs`      | Mengubah dokumentasi                         |
| `chore`     | Maintenance/config umum                      |
| `perf`      | Meningkatkan performa                        |
| `test`      | Menambah/mengubah testing                    |
| `build`     | Mengubah build/dependency                    |
| `ci`        | Mengubah CI/CD                               |
| `revert`    | Membatalkan commit sebelumnya                |
