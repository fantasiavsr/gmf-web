Quick Reference

Environment Variables

VITE_DATA_SOURCE=api          # 'api' or 'mock'
VITE_API_URL=http://localhost:8000/api
VITE_API_TIMEOUT=1000          # ms before fallback

Note: .env is gitignored. Create it locally. Vercel uses mock mode automatically.

Start Development

# Terminal 1: Laravel backend
cd ../editorial-backend
php artisan serve --port=8000

# Terminal 2: React frontend
npm run dev

File Structure
