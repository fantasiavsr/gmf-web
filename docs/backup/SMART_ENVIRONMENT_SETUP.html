Smart Environment Setup

API mode with automatic fallback to mock data — no env file switching needed

The Goal

You want a single `.env` configuration that:

  • Always tries to fetch from the API first
  • Automatically falls back to mock data if the backend fails
  • Works whether or not XAMPP/Laravel is running
  • No need to change `.env` files — just works everywhere

Current Configuration

.env (Single configuration for all environments)
VITE_DATA_SOURCE=api
VITE_API_URL=http://localhost:8000/api
src/services/data.js (The magic)
const DATA_SOURCE = import.meta.env.VITE_DATA_SOURCE || 'mock';
const ENABLE_API_FALLBACK = true; // ← This is key!

How It Works

When the dashboard loads:

1
Component calls productDataSource.getAll()
2
Data service checks: Is VITE_DATA_SOURCE=api? YES
3
Tries: fetch('http://localhost:8000/api/products')
⚡
Decision Point: What's the result?

Scenario 1: Backend is Running ✅

XAMPP on + Laravel running

API request succeeds → Returns real data from database

SUCCESS Dashboard shows 6 products from API

Scenario 2: Backend is Down ⚠️

XAMPP off OR Laravel not running

API request fails → Check ENABLE_API_FALLBACK=true → Use mock data

FALLBACK Dashboard shows mock products (no error!)

Console: ⚠️ API request failed, falling back to mock data

Scenario 3: Network Error 🌐

Connection issue or DNS failure

Any fetch error → Check ENABLE_API_FALLBACK=true → Use mock data

FALLBACK Dashboard gracefully falls back to mock

Test It Yourself

  3. Open: http://localhost:5173/dashboard/products
